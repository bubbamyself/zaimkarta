# Офферы со смешанными стандартными и акционными ставками

Дата локальной проверки: 17 августа 2026 года.

Миграция `20260817090000_offer_promo_display_variant` намеренно не переписывает
существующие финансовые условия. Это защищает данные от автоматической подмены
неподтверждёнными значениями.

В локальной базе найдены четыре активных оффера, где старая стандартная ставка
или ПСК начинается с нуля:

| Оффер | Slug | Старая ставка в день | Старая ПСК | Что проверить вручную |
|---|---|---:|---:|---|
| BelkaCredit | `belkacredit` | 0–0,8% | 0–292% | Обычную ставку и обычную ПСК без акции |
| MoneyMan | `moneyman` | 0–0,8% | 281–292% | Обычную ставку; отдельно проверить акцию 0% |
| Быстроденьги | `bistrodengi` | 0–0,8% | 0–292% | Обычную ставку и обычную ПСК без акции |
| Займер | `zaymer` | 0–0,8% | 0–292% | Обычную ставку и обычную ПСК без акции |

До публикации изменений владелец должен открыть каждый оффер в админке,
проверить официальный источник кредитора и заполнить поле «Стандартная ставка,
% в день» и блок «Стандартная ПСК». Акцию 0% нужно включать только после
заполнения отдельной секции акции с датой и HTTPS-источником.

Для повторной проверки базы после будущего развёртывания:

```sql
SELECT "brandName", slug, "dailyRateFrom", "dailyRateTo", "pskFrom", "pskTo", status
FROM "Offer"
WHERE "dailyRateFrom" = 0
   OR "dailyRateTo" = 0
   OR "pskFrom" = 0
   OR "pskTo" = 0
ORDER BY "brandName";
```

Этот отчёт отражает только локальную базу на указанную дату. Перед production-
миграцией запрос нужно повторить на свежей резервной копии или после безопасного
применения схемы в рамках отдельного production-регламента.
